Sync the Mac install with the merged model and the review UI

The Mac scripts had drifted: they copied neither review.py nor tools/, so the
review UI and merge_ckpt.py/repair.py never reached a Mac install at all. Both
setup_mac.sh and update_mac.sh now carry them.

README_MAC rewritten around the merged checkpoint. It previously told you to
download model_last.pt from Kaggle, which is the model with the broken Marathi.
The section now explains why the fine-tune mispronounces, names
model_voice_merged50.pt as the file to copy, and gives a self-contained recipe
for rebuilding the merge on the Mac - including the key detail that only
_orig_mod. is stripped from the base while ema_model. is kept, which is what
makes all 364 tensors line up.

Also refreshed: NFE guidance (32 is the default now, not 16), and the note that
the review UI runs on 7861 and does not touch the GPU until you press Repair.

pronunciation.json synced at 244 entries, including the अनन्या respellings.
